## Audit & Modernisation (par Old to New - Elie Bendier)

### Démarche d’audit

Ce projet a été audité dans le but de :
- Comprendre l’architecture et les choix techniques initiaux
- Identifier les points forts et les axes d’amélioration
- Proposer une feuille de route de modernisation

### Constats

- Architecture simple, facile à prendre en main
- Utilisation de PHP procédural, peu évolutif à long terme
- Absence de tests automatisés et de gestion des dépendances
- Sécurité perfectible (validation des entrées, gestion des erreurs)
- Documentation utilisateur claire

### Axes d’amélioration proposés

- Refactorisation vers une architecture orientée objet
- Ajout de tests unitaires et d’intégration
- Mise en place d’un gestionnaire de dépendances (Composer)
- Sécurisation des entrées et gestion des erreurs/logs
- Modularisation du code JS et ajout de tests
- Amélioration continue de la documentation technique

### Prochaines étapes

- Refactorisation du backend en PHP OOP
- Ajout de tests automatisés
- Sécurisation des entrées utilisateur
- Modularisation du code JS
- Documentation technique pour les développeurs
